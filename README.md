# Projectile Motion Simulator 🎯

A C++ projectile motion simulator inspired by the PHET Projectile Motion project.  
This is a class project for my C++ and Physics courses at AAUP.

## 💻 Build From Source

Want to compile it yourself? Follow these steps:

1. **Install prerequisites**  
   Make sure you have the following tools installed:

   - **CMake** – for cross-platform builds  
   - A C/C++ compiler – e.g. MinGW-w64 or Clang  
   - **SFML** – graphics/UI library  
   - **vcpkg** (Windows only) – for dependency management  

2. **Clone the repo**  
   ```bash
   git clone https://github.com/Obaidah-Jbreel/motion_simulation.git
   cd motion_simulation
